[req_baf042ae] [deepseek-v4-mod] Request rejected by AI provider (HTTP 400)

  • The provider refused this request before generating anything.
  • Most common cause: its CONTENT FILTER / safety moderation rejected the prompt.
  • Other possible cause: an unsupported request shape — unusual parameters, a malformed tool/function schema, or an attachment this model cannot read. How to fix:
  • Rephrase the prompt and remove policy-sensitive, explicit, or bulk-pasted content.
  • Start a new session/chat so flagged history is not resent on every retry.
  • Simplify the request: drop unusual parameters, oversized tool schemas, and non-text attachments.
  • If you are using a CLI/tool, update it or switch to a supported client (see Recommended tools below). Billing:
  • This request still counts as a request and is billed based on its input (minimum 1,000 prompt / 1,000 completion / 1,000 cached tokens).
  • Do not resend the same request — it will keep failing and keep consuming your quota. Recommended tools:
  • These responses are optimized for opencode, Claude Code, and Codex.
  • If you are using a non-standard client and keep hitting errors, switch to one of the supported tools above.
